## Factual conflicts resolved

1. **Model naming.** Results identify `EPFL-VILAB/flextok_d12_d12_in1k` and `turing-motors/One-D-Piece-S-256`. TiTok is architectural ancestry, not a separate tested model. No TiTok results invented.
2. **Pilot versus confirmatory.** The early HTML says pilot but reports 5,000 images per domain in 200 ImageNet-R classes, which corresponds to the confirmatory cohort. The initial pilot was 500 per domain, 50 classes. Sketch/ObjectNet were an earlier multi-shift extension, not evidence of a later guidance-15 cross-shift replication.
3. **Primary versus full exports.** The current primary uses exact identical 10,000 images per domain across both systems. One-D-Piece's 50,000 ImageNet and 30,000 ImageNet-R exports are a source pool/supplement. Older One-D-Piece adjusted +0.0158 is not merged with the current +0.0229. The separate historical six-budget +0.0157 is retained in its own table.
4. **FlexTok settings.** Guidance 15 at 25 steps with APG is correct for the primary d12-d12 run according to the current report, merged metadata and paper Table 8. The audit retracted a settings-defect claim. Historical extension metadata really does say guidance 7.5. The report distinguishes these configurations instead of retroactively relabelling old results.
5. **Noise control.** The primary batched run uses a batch-derived generator reset at each prefix. It does not establish independently stable per-image seeds across arbitrary changes of batch size or source group. Historical extension metadata separately describes per-image noise.
6. **Analysis chronology.** The September 15 focused HTML/notebook supersede the September 6/7 snapshot in the primary narrative. Absolute and planned 32-token endpoint analyses are reported as confirmatory descriptions; relative progress was added after inspecting results and stays exploratory. The 18-cell focused notebook differs from the recovered 35-cell September 7 snapshot.
7. **Intervals.** Primary results use 5,000 jointly sampled class-bootstrap replicates; historical multi-shift summaries use 10,000. All reported confidence intervals are pointwise. Relative-progress differences are expressed in percentage points, not percentages of semantic information.
8. **Interpretation.** Positive adjusted truncation cost does not imply universally worse raw OOD quality or more tokens for a fixed target. The direct One-D-Piece absolute LPIPS interval at 32 includes zero. Neither report supplies completed semantic-probe or attack results. Earlier audit recommendations for exact matching/absolute curves/paired contrasts are already reflected in the later report.
9. **Historical transcription differences.** Surviving historical JSON gives FlexTok Sketch +0.008049756, rounded +0.0080, while the early HTML says +0.0081. One-D-Piece Sketch intervals are [-0.0204, -0.0130], and ObjectNet intervals are [+0.0241, +0.0347] for FlexTok and [+0.0165, +0.0252] for One-D-Piece. The report uses those saved JSON endpoints rather than the slightly different early HTML transcription. Signs and qualitative conclusions agree; no fresh bootstrap was performed.
10. **Package status.** `vq-tokenizer-properties` is being assembled independently. The report names existing runner/notebook artifacts as reproducibility pointers and labels packaging as separate work; it does not claim an untested end-to-end package reproduction or thesis integration. Package files `tools/prepare_workspace.py`, `tools/run_notebook.py`, `tools/prepare_notebooks.py` and the actual notebook/experiment paths were inspected read-only during assembly.
